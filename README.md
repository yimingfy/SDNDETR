# SDNDETR
code of SDN-DETR.

## 本文的主要贡献总结

1. 指出了现有去噪方法生成的含噪查询与一对一查询噪声分布不一致的问题，并提出采样去噪方法（SDN）予以缓解，该方法包含噪声收集构建器和采样查询生成器两个核心模块；
2. 提出困难噪声构建器，解决难样本稀缺问题，通过注入额外的难噪声样本，提升解码器处理挑战性样本和精修边界框的能力；
3. 大量实验验证了SDN方法能够实现有效的一对多监督，与基线模型相比，SDN-DETR在VisDrone2019数据集上的平均精度提升1.7%，在COCO2017数据集上的平均精度提升2.0%。

## 实验

### 实验设置

数据集与评价指标：为验证SDN-DETR模型的有效性，本文在VisDrone2019[17]和COCO2017[18]数据集上开展实验。参考MS COCO[18]的评价标准，采用不同IoU阈值下的平均精度（AP）作为模型的评价指标。

实现细节：本文选取未使用CDN的RT-DETR模型作为基线模型，所有模型均在NVIDIA 2080Ti显卡上完成训练。训练策略和超参数均遵循RT-DETR的设置：采用AdamW优化器，学习率设为0.0001，输入图像尺寸设为640×640像素。在VisDrone2019数据集上，训练轮数设为350，批次大小设为4；在COCO2017数据集上，报告训练12轮、批次大小为8的实验结果。噪声更新参数M设为5000；对于难噪声集，参数K=5000表示从每个IoU区间中收集5000个噪声样本。

### 整体性能对比

VisDrone2019数据集实验结果：表1展示了本文提出的SDN-DETR模型在VisDrone2019验证集上的实验结果。以ResNet18为骨干网络的SDN-DETR-R18模型达到30.0%的平均精度和49.8%的AP50，性能优于现有方法。与采用CDN实现一对多监督的RT-DETR-R18模型相相比，SDN-DETR-R18模型的AP提升0.8%、AP50提升1.0%、AP75提升1.0%，这表明SDN方法能够提供比CDN更有效的一对多监督。究其原因，SDN方法能够生成与一对一查询噪声分布相近的含噪查询，缓解了噪声分布不一致问题，从而提升了模型性能。

COCO2017数据集实验结果：为验证SDN方法的训练加速效果，本文在COCO2017数据集上训练SDN-DETR模型12轮，实验结果如表2所示。与未采用一对多监督的基线模型相比，SDN-DETR的平均精度提升2.0%，验证了SDN方法在加速模型收敛方面的有效性。与采用CDN作为一对多监督方法的RT-DETR相比，SDN-DETR的平均精度提升0.5%，表明SDN方法的训练加速效果优于CDN。与其他采用一对多监督的DETR模型相比，SDN-DETR的平均精度分别比Group-DETR和H-Deformable-DETR高1.0%和0.3%，且所需的额外查询数量远少于二者。值得注意的是，SDN-DETR仅使用DINO三分之一的一对一查询数量，便达到了与DINO相同的平均精度，这表明SDN-DETR能够以较低的计算量实现具有竞争力的检测性能。
